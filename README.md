# Neon Drift ⚡

A neon arcade racing game that runs in your browser—no install required.

## Play

Open `index.html` in a browser, or enable GitHub Pages in **Settings → Pages** and choose the `main` branch / root folder.

## Controls
- Left / Right arrows: steer
- Up arrow: boost
- Avoid traffic and collect cyan orbs

Your best score is saved in your browser.
